# Pages

## Home
First page of hospli.app.
Introduces the app.

## Log In
Form with textfields for an email and a password to authenticate the user.

## Sign Up
Form with textfields for a name, an email, a password and a password confirmation to create a new user.

## Onboarding
Setup steps after Sign In. Log in to github to connect with the users github account.

## Daily
A dynamic page with dailies. Default is today's daily, there is also a calenddar view to choose a previous daily.

## Summary
A dynamic page with either a list of summaries or a specific summary when a summary from the list has been selected.
